## 11. 운영 절차

### 상품 등록
1. `/meatmall/admin/dashboard.html` 로그인
2. **➕ 상품등록** 탭 클릭
3. 카테고리 선택 (삼겹살/오겹살/목살/앞다리살/미박앞다리살/등심)
4. 상품명·가격·재고·원산지·중량 입력
5. **저장** 클릭 → 즉시 쇼핑몰에 반영

### 무통장 입금 확인 절차
1. 관리자 대시보드 → **📦 주문관리** 탭
2. 상태 `입금대기🏦` 주문 클릭
3. 입금자명·금액 확인 후 **✅ 입금확인** 버튼
4. 상태 자동 변경: `pending_deposit` → `preparing`
5. 포인트 1% 자동 적립

### 주문 상태 변경
관리자 주문관리 → 주문 클릭 → 상태 드롭다운 변경

### 운영키 전환 (현재 테스트 모드)
```
Vercel → Environment Variables
NICE_CLIENT_KEY = live_ck_실제키값
NICE_SECRET_KEY = live_sk_실제키값
→ Deployments → Redeploy
→ 관리자 결제설정에서 "운영 모드 LIVE" 확인
```
